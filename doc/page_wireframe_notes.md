## 2. 文档目标

本文档用于把页面结构进一步明确为“可画图、可搭页面、可联调”的线框级说明。

本文档重点回答：

1. 每个页面模块如何排布
2. 哪些信息要优先显示
3. 哪些区域需要预留状态位
4. 桌面端首版推荐布局是什么
5. 移动端或窄屏如何降级

### 2.1 说明

- 本文档是线框说明，不是最终视觉稿
- 模块名称与组件拆解文档保持一致
- 页面内容以 V1 主链路为准

---

## 3. 绘制约定

## 3.1 线框层级

建议线框只表达以下内容：

- 区块层级
- 信息优先级
- 操作位置
- 状态位置

不表达：

- 最终配色细节
- 最终图标风格
- 最终字体细节

## 3.2 页面宽度假设

桌面端默认：

- 内容区最大宽度：`1200px - 1280px`

表单页默认：

- 中心内容宽度：`680px - 760px`

## 3.3 术语约定

- `Header`：页面头部
- `Control Bar`：切换、筛选、操作区
- `Summary`：结果摘要区
- `State Block`：空态 / 弱信号 / 错误态容器
- `List`：榜单列表
- `Panel`：详情面板

---

## 4. 全局页面骨架

## 4.1 桌面端全局布局

建议所有主页面采用统一骨架：

```text
+--------------------------------------------------------------+
| Top Nav / AppShell                                           |
+--------------------------------------------------------------+
| Page Header                                                  |
+--------------------------------------------------------------+
| Main Content                                                 |
|                                                              |
|   page-specific modules                                      |
|                                                              |
+--------------------------------------------------------------+
```

### 顶部导航建议

仅保留必要项：

- Logo / Product Name
- Discover
- Settings
- Login / User Menu

V1 不建议塞入过多全局导航。

## 4.2 全局状态位

全局层应预留：

- 顶部 toast 区
- 全局 error banner 区
- 导出进度浮层或轻提示区

## 6. 一键发现页线框

## 6.1 页面目标

- 低成本发起模板化查询

## 6.2 桌面端线框

```text
+--------------------------------------------------------------+
| Top Nav                                                      |
+--------------------------------------------------------------+
| Page Header                                                  |
|  One-click Discover                                          |
|  Short description                                           |
+--------------------------------------------------------------+
|                     OneClickQueryForm                        |
|  +--------------------------------------------------------+  |
|  | TopicTemplateSelector                                  |  |
|  +--------------------------------------------------------+  |
|  +-----------------------+ +-----------------------------+  |
|  | TimeWindowPicker      | | ViewTypeToggle              |  |
|  +-----------------------+ +-----------------------------+  |
|  +--------------------------------------------------------+  |
|  | QueryDescriptionHint                                   |  |
|  +--------------------------------------------------------+  |
|  +--------------------------------------------------------+  |
|  | QuerySubmitBar                                         |  |
|  +--------------------------------------------------------+  |
+--------------------------------------------------------------+
| Help / Notes                                                 |
+--------------------------------------------------------------+
```

## 6.3 结构说明

- 表单主体居中
- 模板选择占满一行
- 时间范围与视角选择并排
- 提交按钮单独一行，避免和说明混在一起

## 6.4 状态位

- 模板 selector 内支持 loading / error / empty
- submit bar 内支持 warning / loading

## 6.5 交互建议

- 选择模板后，页面可显示简短模板说明
- 提交后：
  - cache hit -> 直接跳结果页
  - async -> 跳任务页

- 提交区上方

这样用户在点击前就能看到。

- 关键词过泛 warning
- 歧义 warning
- 超限 error

## 8. 查询任务页线框

## 8.1 页面目标

- 给异步任务一个清晰可理解的承接页

## 8.2 桌面端线框

```text
+--------------------------------------------------------------+
| Top Nav                                                      |
+--------------------------------------------------------------+
| Page Header                                                  |
|  Query in Progress                                           |
+--------------------------------------------------------------+
| QueryTaskStatusCard                                          |
|  [StatusBadge] [Current Stage] [Progress Bar]               |
+--------------------------------------------------------------+
| QueryConditionSummaryCard                                    |
|  query summary / time range / view type                     |
+--------------------------------------------------------------+
| CoverageNoticeBanner (optional)                              |
+--------------------------------------------------------------+
| QueryTaskWarningList (optional)                              |
+--------------------------------------------------------------+
| QueryTaskActionBar                                           |
|  [Refresh] [Back to Edit] [View Result if available]         |
+--------------------------------------------------------------+
| QueryTaskErrorPanel (only if failed)                         |
+--------------------------------------------------------------+
```

## 8.3 布局原则

- 任务状态卡必须居上
- 当前阶段和进度必须是一眼可见信息
- 若 partial_success，`View Result` 必须很明确

## 8.4 状态变体

### pending

- 只显示“任务已创建，等待执行”

### running

- 显示 stage + progress

### partial_success

- 顶部状态卡 + coverage banner + 查看结果按钮

### failed

- 错误面板置底，但需可见

## 9. 结果页线框

## 9.1 页面目标

- 快速展示一次结果快照的主要需求结果

## 9.2 桌面端主布局

```text
+--------------------------------------------------------------+
| Top Nav                                                      |
+--------------------------------------------------------------+
| ResultSummaryHeader                                          |
|  query summary / time range / generated_at / view type       |
+--------------------------------------------------------------+
| CoverageNoticeBanner (optional)                              |
+--------------------------------------------------------------+
| SyncFreshnessBanner                                          |
+--------------------------------------------------------------+
| ResultControlBar                                             |
|  [BoardTabs]                               [ExportButton]    |
+--------------------------------------------------------------+
| ResultStateBlock (conditional)                               |
+--------------------------------------------------------------+
| BoardList                                                    |
|  [BoardListItem]                                             |
|  [BoardListItem]                                             |
|  [BoardListItem]                                             |
+--------------------------------------------------------------+
| PaginationFooter / Load More                                 |
+--------------------------------------------------------------+
```

## 9.3 信息优先级

### 第一优先级

- 这是什么结果
- 当前时间范围
- 当前榜单类型

### 第二优先级

- coverage note
- freshness note

### 第三优先级

- 榜单项本身

## 9.4 BoardListItem 线框建议

```text
+--------------------------------------------------------------+
| #1  [Title]                               [Score / Badges]   |
| Summary text...                                               |
| [discussion] [attention] [growth] [confidence]               |
| [subreddit tag] [subreddit tag]                               |
| "highlight evidence excerpt..."                               |
+--------------------------------------------------------------+
```

## 9.5 状态位布局建议

### 无结果

- 替换 BoardList 区域

### 样本不足 / 低置信度 / partial_success

- 不替换列表
- 用 banner 或 state block 叠加说明

## 10. 详情页线框

## 10.1 页面目标

- 解释单个需求为什么成立

## 10.2 桌面端布局建议

推荐采用 **8/4 双栏布局**：

```text
+--------------------------------------------------------------+
| Top Nav                                                      |
+--------------------------------------------------------------+
| ClusterDetailHeader                                          |
|  title / summary / back                                      |
+--------------------------------------------------------------+
| CoverageNoticeBanner (optional)                              |
+--------------------------------------------------------------+
|                 Main Content 8 cols | Side Panel 4 cols      |
|--------------------------------------------------------------|
| ClusterProblemSection              | ClusterScorePanel       |
|  scenes                            | ClusterMetricPanel      |
|  pain points                       | ClusterTagList          |
|  alternatives                      | Community Summary       |
|--------------------------------------------------------------|
| SupportingEvidencePanel            |                         |
|--------------------------------------------------------------|
| OpposingEvidencePanel              | ClusterActionBar        |
+--------------------------------------------------------------+
```

## 10.3 主内容区优先顺序

1. scenes
2. pain points
3. alternatives
4. supporting evidence
5. opposing evidence

## 10.4 侧栏优先顺序

1. 分数
2. metrics
3. 标签
4. 社区信息
5. 导出动作

## 10.5 EvidenceCard 线框建议

```text
+--------------------------------------------------------------+
| "excerpt..."                                                 |
| [subreddit] [time] [availability status]     [Open Source]   |
+--------------------------------------------------------------+
```

## 10.6 低置信度详情页处理

低置信度不是换布局，而是：

- 在 header 下方增加提示
- 在 score panel 中明显标记

## 13. 响应式与窄屏降级建议

## 13.1 总体原则

V1 首版以桌面端优先，但不应完全忽视窄屏可读性。

## 13.2 窄屏降级规则

### 查询页

- 并排控件改为上下堆叠

### 结果页

- ControlBar 折行为上下两层
- BoardListItem 改成单列信息流

### 详情页

- 8/4 双栏改为单列
- score panel 提前到正文前

## 13.3 移动端不建议首版重点优化

V1 可做到：

- 可浏览
- 可操作

但不要求做到最佳移动端体验。

---

## 14. 线框出图优先级建议

建议设计按以下顺序出线框：

1. 结果页
2. 详情页
3. 查询任务页
4. 定向发现页
5. 一键发现页
6. 首页
7. 设置页

### 原因

- 结果页和详情页最能定义产品价值
- 查询任务页最能定义异步任务体验

---

## 15. 联调前必须定下来的页面决策

以下决策在进入高保真或前端实现前建议锁定：

1. 结果页榜单是否默认 Top 20
2. 详情页是否首版独立路由页
3. active / new 切换是否回到任务创建逻辑
4. evidence 是否首版分页
5. 导出按钮在结果页和详情页是否都保留

---

## 16. 一句话结论

页面线框设计的关键，不是把页面画得更满，而是：

> **围绕查询上下文、结果可靠性、榜单信息密度和证据可追溯性，把页面骨架先稳定下来。**
